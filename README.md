# ambience

an amazing web proxy powered by Ultraviolet. we have everything you can imagine

## features

- **custom js** – ambience auto detects when a site has a custom script and asks if you want to use it, allowing for custom scripts on your favorite sites.
- **sleek & modern UI** – modern and easy to use UI that will have you looking at it for hours.
- **fully customizeable** – change settings to your perfection.
- **12+ themes** – different themes for everyone.

## hosting/running
docker (recommended)
```shell
docker build . -t ambience
docker run -p 8080:8080 ambience
```
